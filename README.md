# 压缩包整合工具 v1.3

一个面向 Windows 的压缩包整合工具。它可以把多个压缩包解压到同一工作目录，再重新输出为一个压缩包，适合整理分卷包、素材包和下载包。

本仓库同时包含 Windows 目录版和对应的 v1.3 源代码。二进制下载仍在 Release 中，源代码用于审查、修改和本地运行。

## 直接下载

Windows 用户下载并解压下面的完整运行包，双击其中的 `压缩包整合工具v1.3.exe` 即可使用：

[下载压缩包整合工具 v1.3.0](https://github.com/xiaohuangya617/archive-integration-tool/releases/download/v1.3.0/archive-integration-tool-v1.3.0-windows-x64.zip)

请使用“解压全部”保留目录结构，不要只提取 EXE 文件。

## 功能

- 支持通过文件选择或拖拽添加多个压缩包。
- 支持 ZIP、RAR、7Z 输出格式。
- 可设置原文件名、连接符和输出文件名规则。
- 支持列表内拖拽排序，点击文件名可复制去掉扩展名后的名称。
- 输出前估算所需磁盘空间，并显示目标磁盘可用空间。
- 检测同名文件冲突，并在整合前选择统一的冲突处理方式。
- 支持“完成后清空”当前任务列表，保留输出目录方便连续处理。
- 可选在整合完成后删除源压缩包；删除前会再次确认，并尝试移入回收站。
- 目录版发布，已包含运行所需的 Python、pywebview 及压缩相关运行库，无需单独安装 Python。

## 使用方法

1. 双击运行 `压缩包整合工具v1.3.exe`。
2. 添加需要整合的压缩包，并按需要调整顺序、命名规则和输出目录。
3. 选择输出格式，确认磁盘空间和冲突处理方式。
4. 点击“开始输出”，等待完成报告。

RAR 输出需要本机安装并可调用 WinRAR。ZIP 和 7Z 输出不依赖 WinRAR。

## 从源码运行

源码运行需要 Windows、Python 3.10 或更高版本，以及 Microsoft Edge WebView2 Runtime：

```powershell
python -m pip install -r requirements.txt
python main.py
```

主要源码位于 `main.py`、`core/` 和 `ui/index.html`。测试脚本位于 `测试/`；测试压缩包不会提交到仓库，可按需运行 `make_test_packs.py` 或 `make_real_cases.py` 生成。

## 发布内容

这是 Windows 目录版程序，运行时需要保持下列结构不变：

```text
压缩包整合工具v1.3/
├─ 压缩包整合工具v1.3.exe
├─ _internal/
└─ config.json
```

请不要只复制主程序 EXE；缺少 `_internal` 目录会导致程序无法启动。

## 已知缺陷和限制

- 源码已随仓库提供，但当前源码发布快照没有提交 PyInstaller 构建缓存和完整构建环境；二进制 Release 仍是面向普通用户的推荐下载方式。
- 仅支持 Windows；未对 macOS、Linux 或移动设备做适配。
- RAR 输出依赖本机 WinRAR。未安装 WinRAR 或命令行路径不可用时，RAR 输出无法完成。
- 处理大体积压缩包时需要足够的临时解压空间和输出空间；磁盘预估是运行前估算值，不能替代实际容量检查。
- 当前版本已做启动和界面元数据检查；不同压缩格式、损坏压缩包、密码压缩包、极端同名冲突等场景仍建议使用副本进行验收。
- “删除源文件”是不可逆的用户操作。启用后请确认待删除列表，重要原件应先备份。
- `config.json` 是运行时生成的本地配置，不随源码提交；跨电脑使用时程序会重新生成默认配置。
